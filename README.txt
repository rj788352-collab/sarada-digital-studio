SARADA DIGITAL STUDIO — starter app
===================================

Included:
- Responsive Bengali-first studio website
- Black and gold premium design
- Services, sample gallery, indicative pricing section
- Booking form that composes a WhatsApp message to +91 99327 14438
- PWA manifest and service worker for supported browsers

Important before publishing:
1. Gallery photos are sample external images. Replace them with photos you own or have permission to use.
2. Prices are intentionally shown as “contact for pricing”; add confirmed prices only.
3. Booking is sent to WhatsApp; there is no server/database and bookings are not automatically stored.
4. Host this folder on HTTPS (for example, a static hosting provider) for installability/service-worker support.
5. To make an APK, package the hosted PWA using a trusted Android PWA/TWA workflow. An APK is not included in this ZIP.
6. The WhatsApp booking link uses country code +91 and the supplied number 9932714438. Verify the number has WhatsApp before publishing.

Quick test:
- Open index.html in a browser for a basic preview.
- For PWA install/service worker, serve the folder over HTTPS or a local web server.
